# Security Policy

## Reporting Security Vulnerabilities

We take the security of this e-learning platform and the privacy of its users very seriously. If you discover a security vulnerability, **please DO NOT report it via a public GitHub issue**.

Instead, please send a responsible disclosure report directly to our core security team:

* **Telegram**: [https://t.me/trading_world_support](https://t.me/trading_world_support)
* **Zalo / Phone**: [+84 971 929 521](https://zalo.me/84971929521)

### What to include in your report:
1. Type of vulnerability (e.g., SQL Injection, XSS, SSRF, Broken Access Control, Authentication Bypass).
2. Detailed step-by-step reproduction instructions or proof-of-concept (PoC).
3. The affected URLs, API endpoints, or code components.
4. Any potential remediation recommendations.

### Our Commitment:
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for investigation and patch deployment.
- We will notify you once the fix has been verified and released to the main branch.
- We respect ethical security researchers and will credit you in our security advisories upon request.
